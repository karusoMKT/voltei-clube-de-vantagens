# Voltei Clube de Vantagens

Crie um web app mobile-first (PWA instalável) chamado Voltei: um clube de fidelidade para comércios locais no Brasil. Idioma: português do Brasil. Stack: React, TypeScript, Tailwind e Supabase.

Visual: azul e branco, acolhedor, simples e fácil de usar. Cores: azul #2F6BDE, texto navy #14284B, fundo #F5F9FF, azul claro #E3EEFF, amarelo #FFB938, creme #FFF1D6, borda #DCE7F8, texto secundário #4F5F80. Fonte Nunito. Cantos bem arredondados (16 a 24px), botões com no mínimo 48px de altura e textos curtos e amigáveis.

Estrutura com três áreas:
1. App do cliente em /cliente, com barra de abas: Início, Prêmios, Meu QR, Perfil.
2. Painel da empresa em /empresa, com abas: Caixa, Aprovar, Prêmios, Resumo.
3. Área do dono da plataforma em /admin.

Por enquanto crie só a navegação e telas vazias com título. Sem lógica e sem funcionalidades que eu não pedi.
